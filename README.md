# Physics-informed graph neural networks

[![Static Badge](https://img.shields.io/badge/Paper-Medical_Image_Analysis-orange)](https://www.sciencedirect.com/science/article/pii/S1361841526000435)

This repository contains the official implementation of **Physics-informed graph neural networks for flow field estimation in carotid arteries** ([arXiv](https://arxiv.org/abs/2408.07110)).

<p align="center">
  <img src=".img.png" width="900">
</p>

## Description
Since our data cannot be shared due to patient privacy, this repository primarily functions as reference implementation for the methods used throughout this work.
